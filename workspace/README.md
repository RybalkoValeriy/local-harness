# My first local agent workspace

This folder is the default workspace for Local Harness.

The app uses Ruby on Rails, SQLite, Hotwire, and a local Qwen3.5 9B model served by LM Studio.
The assistant can list, read, create and edit text files here using project-scoped tools. It cannot run commands or delete files.
